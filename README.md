# formwork-site

Marketing page for Formwork — tryformwork.com.

Static site: `index.html` + `styles.css` + `main.js`, no build step. Open `index.html` in a browser to preview.

## Design language

The page is styled as a construction document set — a fixed drawing-sheet frame with
registration ticks, sections numbered like spec divisions (01 Site Conditions, 03 Scope
of Work…), dimension-line headers, a takeoff table, and a title block for the footer.
Square corners and 1px rules throughout; brand palette and type per
`assets/branding/formwork_brand_guidelines.png` (Big Shoulders Display / Instrument
Sans / Geist Mono, self-hosted in `assets/fonts/`).

`og-image.png` is the social card (1200×630), drawn in the same sheet style.
